03 / REQUEST REAL OPENSees SOLVE

Send the configured scenario to GitHub Actions

Authenticated GitHub account required; public issue body contains only the synthetic numeric scenario.

This website cannot directly invoke a private backend without credentials. Instead, Queue OpenSees run prepares a GitHub issue with the validated configuration. Review the issue, press Submit new issue, and the repository owner's authenticated submission triggers the 2D OpenSees job. The job uploads a reproducible JSON result and posts its run link in the issue.

Submitting the GitHub issue is the confirmation step. The repository restricts the automatic job to its owner. No GitHub access token is requested or saved by this webpage.
