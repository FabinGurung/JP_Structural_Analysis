STRUCTURAL ANALYSIS REPORT

Six report stages

Each stage follows the calculation pipeline, not the original software application's screenshots.

01

Basis and geometry

Site/source provenance; architecture and floor plans; materials, member sections, soil and selected code editions.

Source inputs must be independently confirmed
02

Gravity, mass and seismic actions

Wall, finish, live and self-weight loads; floor mass; ESM/MRSM spectra, seismic coefficients and load combinations.

Bounded functions available; placement and verified site inputs pending
03

Analysis and structural response

3D frame analysis, periods and modal masses; force diagrams; drift, torsion and storey irregularities.

Bounded frame and response results; full acceptance pending
04

Member and foundation design

RC beams/columns/joints; slabs, stairs and isolated/combined foundations; optional Winkler raft.

Only preliminary detailing checks; full capacity/reinforcement design missing
05

Independent checks and failures

Force/moment equilibrium, applicable code thresholds, independent examples, unsafe design and unresolved source conflicts.

Unsafe worksheet results remain FAIL—never silently adopted
06

Reproducible SAR and archive

Result IDs, formulas, code clauses, schedules, graphs, calculation tables, LaTeX/PDF and machine manifest.

Draft template exists; approved complete report not yet generated
