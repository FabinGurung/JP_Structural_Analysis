Procedure — how every solver result was obtained

  1. Prove source identity. Verify both original ETABS21 file SHA256s and compare native ULS/SLS supports, diaphragm assignment records, load cases, elastic properties and section modifiers.
  2. Build the graph. Connect beam/column ends at the original point+storey identities. Check each frame-only component has a path to an actually restrained base node; exclude the four unsupported islands, not cover them with invented fixities.
  3. Form member stiffness. Read section A, E, ν and shape. Compute G=E/[2(1+ν)], I22 and I33 for source shapes, apply the actual ULS or SLS I2/I3 factors and source J factor, noting rectangular torsion is a declared Saint-Venant approximation.
  4. Apply actual source loads. Only the 70 original uniform WALL LOAD assignments on supported concrete BEAM objects enter the bounded run. For each, integrate w×L, project gravity to local beam axes and apply a three-dimensional beamUniform load.
  5. Solve and validate. Assemble 3D elasticBeamColumn frame stiffness, apply original source base restraints, solve Kff·uf=Ff in OpenSeesPy and recover 12 signed member end actions. Check the sum of all base reactions against the applied load before publishing.
  6. Hold unmodeled physics visibly. Diaphragm/shell load transfer, original meshing, selfweight, partial-span line loading, modal eigenvectors and design combinations remain outside this deliberately bounded case.
