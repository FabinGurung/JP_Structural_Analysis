What GitHub, Actions, Pages and Drive each own

Google Drive

Authority for original private E2K models, historical PDF, drawings and evidence. The current publisher does not fetch live E2K files on every run.

GitHub repository

Versioned Python/OpenSees engine, de-identified derived source snapshots, code basis, checks, tests and report build logic. A snapshot pin is not automatic Drive synchronization.

GitHub Actions

Runs pinned numerical scripts and 600+ regression/browser tests, produces manifests, then verifies Pages source SHA and engineering hold flags. Successful CI is software QA.

GitHub Pages

Displays reproducible, source-labelled calculations, visual inspection and research reports. It is a presentation surface, not a new structural solver or a shared design database.
