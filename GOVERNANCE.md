# Governance

Mode: A9-GOVERNED / LIVE-GITHUB-FIRST / SOURCE-PRESERVING / FAIL-CLOSED.

1. Preserve originals read-only; derived data never masquerades as source evidence.
2. Never guess unresolved engineering parameters. Use UNRESOLVED.
3. Preserve source -> normalized entity -> analysis -> result -> report lineage.
4. Record PRE state before material repository mutations.
5. Work on one dedicated structural-engine branch until verification.
6. Do not mutate unrelated repositories or their GitHub Pages.
7. Public examples must be synthetic or explicitly sanitized/approved.
8. A governed result records model, configuration, solver/version, units, case/combination, run ID and lineage.
9. CI success is software evidence, not engineering approval.
10. Final validation is blocked by material FAIL or UNRESOLVED findings.

Professional states: MODEL_QA_PASS, NUMERICAL_VALIDATION_PASS, REPORT_GENERATED, ENGINEER_REVIEW_REQUIRED, UNRESOLVED, BLOCKED.
