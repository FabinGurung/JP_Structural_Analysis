# R6.26 Narayani — independent report replication (engineering HOLD)

A six-chapter structural-analysis report generated by our OpenSeesPy engine, not by ETABS. Original headings retained, actual signed member actions, displacement and 23 base reactions computed from a 3D assumed frame with original source GF drawing marks.

Physical source: 23 GF column marks, 21 footing outlines, candidate original DXF beam edges; their nearest-column support snaps and vertical continuation are ASSUMED. Original drawing report 3.05m level height, 0.13m slab, 0.23x0.4m beams, 2kPa ordinary residential room, M20/Fe500, E=22360.68MPa; concrete gamma 20kN/m3 user approved. Missing occupancy/wall/slab support data are not invented. Approximate 1.5kPa finishes and uniform architectural floor area proxies are labelled. Walls not applied. Two 10kN/floor lateral probes are NOT seismic code actions. Linear elastic 3D frame only; no slab shells, stairs, code seismic/wind, nonlinear RC, soil/foundation design or reinforcement proof.

OpenSees cases: DL, LL, PX10, PY10; signed twelve-component local member I/J actions, six-axis equilibrium, reactions and displacements generated independently. Publication creates HTML with original chapter sections 1–6 and annex, original-model source JSON, signed result JSON, per-member and per-support CSV and SHA256 receipt.

F3 original NOT SAFE IN ONE WAY SHEAR remains adverse. PASS of OpenSees equilibrium only means assumptions are algebraically balanced; no engineering design approval, authority approval or construction release. The r6.24-preview tag remains the last prerelease.

Reproduce after checking out the pinned CAD repo at SHA 259d11e1543e4ba7040373a752b823396e12d7f8: install openseespy 3.8 and pytest, then run python -m r6p26.publish --cad-root drawing-source --site-dir build/site. Existing Pages workflow installs the engine and verifies output + live report.
