# Reporting methodology

SAR structure is derived from the actual supplied government/municipality report, not a generic AI template.

The blueprint records section order, titles, tables, figures, calculation blocks, cover metadata, headers/footers, numbering, units, code references, result tables and appendices.

Only validated implemented design/check modules may be represented as design checks. OpenSees force output alone is not RC/steel design.

Signatures, seals, certification and government approval are never fabricated.
