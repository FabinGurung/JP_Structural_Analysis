## R6.1 audited synthetic MRSM and independent P–Delta benchmark — CI and Pages governed

The R6.1 software increment adds a governed, **independently synthetic seismic-reference stage** to the existing canonical OpenSees 3D frame and source-mass pipeline, without claiming to have completed a code-compliant original-building seismic design. From the R5 original synthetic gravity ledger (128kN), the audited source participation factors produce **111.2kN seismic-eligible weight**, assigned to the same four original roof nodes as mass `m=W/g` in `kN·s²/m`, with original assembly SHA and all source-unit conservation guards retained.

An explicitly identified flat *synthetic* acceleration spectrum with (S_a=2m/s²), damping ratio 5% and caller-supplied full X/Y transverse torsion probes is passed to the already-tested `canonical_seismic.py` engine. A caller-declared `CQC` within-direction 6-mode MRSM yields frequencies/periods, participating/effective masses, cumulative participation ratios, X/Y dynamic response-spectrum base shear, actual two-storey interstorey drift and roof torsional probe rotations. Independent small-data `SRSS(3,4)=5` and equal-mode `CQC rho(i,i)=1` are hard QA. Orthogonal-direction envelope uses an explicit **illustrative 0.30 source factor**, not an assumed NBC code mandate. The mode count, spectrum, acceleration units, damping, mass source and response/torsion node geometry fail closed on untrusted or unsupported fields. This is a **canonical elastic frame MRSM**, NOT connected ShellMITC4 dynamic eigen solution and not real Nepal site seismic spectra.

A separate **3D elastic cantilever numerical PDelta benchmark** compares the same `elasticBeamColumn` using `geomTransf Linear` versus `PDelta` for three declared independent axial compressions, preserving base reaction force equilibrium, verifying zero-P exact hand formula `Fx L³ / (3 E I)`, and proving monotone second-order amplification. Euler stability ratio bounds the synthetic test so unstable or physically unrepresentative cases are refused. This benchmark is **not** a whole-building P-Delta check and carries no actual project loads.
