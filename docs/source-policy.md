# Source policy

Original government/municipality submission files are evidence, not public repository fixtures by default.

Preferred transparent model exchanges are E2K, S2K, tabular/text exports, CSV/XLSX, response-spectrum data and report tables. Binary EDB parsing is not claimed unless a verified parser is introduced and tested.

Historical/submitted code editions remain the ORIGINAL SUBMISSION BASIS. A newer-code review is a separate CURRENT-CODE REVIEW lane.
