# Validation policy

Validation layers: closed-form/textbook; native transparent solvers; independent open-source engines; and original commercial/submission results supplied as evidence.

Never average FE-engine outputs. Investigate units, axes, formulation, offsets, rigid zones, releases, supports, diaphragms, mass, self-weight, load signs, meshing, coordinate conventions, stiffness modifiers, P-Delta, damping, eigensolver behavior, spectrum interpolation and combination/envelope logic.

Each comparison stores quantity, location, case, engines, values, absolute/relative difference, tolerance, status and explanation.
